# 우리 가게 쇼핑몰 꾸러미 (설명서 한 장)

컴퓨터를 잘 몰라도 **메모장으로 글자만 바꾸면** 쓸 수 있는 작은 가게 홈페이지입니다.
프로그램 설치가 필요 없고, GitHub Pages(연습용)와 Cloudflare Pages(실제 가게용)에 그대로 올리면 됩니다.

## 들어 있는 파일

| 파일 | 하는 일 | 고치나요? |
|---|---|---|
| `products.txt` | 상품 목록 (이름, 가격, 사진, 설명, 품절) | **예, 자주** |
| `shop-info.txt` | 가게 이름, 전화번호, 계좌, 배송 안내, 사업자 정보 | **예, 처음 한 번** |
| `images` 폴더 | 상품 사진 (예시 그림 4장과 미리보기 그림 1장) | **예, 사진을 바꿀 때** |
| `index.html` | 첫 화면. 맨 위 "여기만 바꾸세요" 부분만 고칩니다 | 처음 한 번 |
| `privacy.html` | 개인정보처리방침 예시 | 판매 전 확인 |
| `terms.html` | 이용약관 요약 예시 | 판매 전 확인 |
| `style.css`, `shop.js` | 화면 모양과 동작 | 아니요 |

## 상품 하나 적는 법 (`products.txt`)

```
상품명: 햇사과 5kg
가격: 35,000원
단위: 1상자
사진: apple.jpg
설명: 아침마다 직접 딴 사과입니다.
상태: 판매중
```

- 상품과 상품 사이에는 **빈 줄 한 줄**을 넣습니다.
- 품절이면 `상태: 품절`, 잠시 내리려면 `상태: 숨김`이라고 적습니다.
- 사진 파일 이름은 **영어 소문자와 숫자**로 짓는 것이 가장 안전합니다. (예: `apple.jpg`)
- `#`으로 시작하는 줄은 메모라서 화면에 나오지 않습니다.
- 할인 전 가격은 `원래가격:`, 스마트스토어 같은 다른 판매 주소는 `구매링크:`에 적습니다.

## 꼭 알아 둘 것

1. **GitHub Pages는 연습용으로만** 쓰세요. GitHub 안내문은 GitHub Pages를 온라인 사업이나 전자상거래용 무료 호스팅으로 쓰는 것을 허용하지 않습니다. 그래서 `*.github.io` 주소에서는 화면 맨 위에 "연습용 화면입니다" 띠가 저절로 나옵니다.
2. 실제로 팔 때는 Cloudflare Pages 같은 곳에 올리고, `shop-info.txt` 아래쪽 **사업자 정보**를 모두 채우세요. 비어 있으면 화면 맨 아래에 노란 안내가 나옵니다.
3. 이 홈페이지는 카드 결제를 받지 않습니다. 주문은 전화·문자·카카오톡·주문서로 받고, 돈은 계좌이체나 다른 판매처(구매링크)로 받습니다.
4. 컴퓨터에서 `index.html`을 두 번 눌러 열면 상품이 안 보입니다. 인터넷에 올린 주소로 확인하세요.
5. 글자가 깨지면 메모장에서 **다른 이름으로 저장 → 인코딩: UTF-8**로 저장하세요. (EUC-KR로 저장한 파일도 웬만하면 읽습니다)
